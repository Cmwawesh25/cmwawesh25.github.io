Flux Client

A community Minecraft: Java Edition launcher for Windows, focused on PvP add-ons and better performance.

What it does

  • Installs and launches Minecraft: Java Edition, from version 1.7.10 to the current releases.
  • Adds a configurable in-game HUD: FPS, CPS, ping, keystrokes, armor, potion effects, coordinates and more.
  • Improves performance with its own optimizations and open-source mods such as Sodium.
  • Generates an optional interface theme and high-resolution textures on the player's PC, from their own game files.

Why it needs Microsoft sign-in

Players sign in with their own Microsoft account to prove they own Minecraft and to play on online servers. The launcher uses the device code flow: the player signs in on Microsoft's own page and never types their password into the launcher.

The only permissions requested are XboxLive.signin and offline_access. The Minecraft Services API is used to obtain a game token and to read the player's Minecraft profile.

Data and privacy

  • Flux Client has no server and no account system of its own, and no analytics.
  • Sign-in tokens are stored on the player's PC, encrypted with the Windows credential protection when it is available.
  • Tokens are only sent to Microsoft, Xbox Live and Minecraft services, and to the game itself.
  • The launcher also downloads game files from Mojang, Fabric, Adoptium and Modrinth, and reads public server status from mcstatus.io and mcsrvstat.us. These requests do not include sign-in tokens.
